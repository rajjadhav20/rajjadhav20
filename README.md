### 🔭 Latest Project

**TC-to-MES Data Ingestion Pipeline & Monitoring Dashboard**

A real-time data integration solution designed to ingest PLM data and synchronize it with MES workflows.

**Technology Stack:**

`Node.js` `Express.js` `React` `MongoDB` `Socket.io`

The pipeline supports data ingestion from:

- JSON
- XML
- Excel

It validates incoming data, processes synchronization workflows, and streams live logs to an MES monitoring dashboard using WebSockets.
